**要約**:

【何が更新されたか】  
Azure Virtual Networkにおいて、Equal-Cost Multi-Path (ECMP) routingがパブリックプレビューとして提供開始されました。

【主な変更点や新機能】  
ECMPルーティングにより、ユーザー定義ルート（UDR）を使って複数のネットワークアプライアンス間でトラフィックを均等に分散できるようになりました。これにより、最大16個までのネクストホップを設定可能です。従来は単一のネクストホップしか指定できませんでしたが、ECMP対応により冗長性やスケーラビリティが向上します。

【影響を受ける対象】  
Azure Virtual Networkを利用しているユーザーや、複数のネットワークアプライアンス（ファイアウォール、ロードバランサー等）を構成している技術者が主な対象です。特に高可用性や負荷分散を必要とするネットワーク設計に有効です。

【注意点】  
本機能はパブリックプレビュー段階のため、本番環境での利用には慎重な検討が必要です。また、ネクストホップの設定は2～16個まで対応しています。詳細や制約事項については公式ドキュメントを参照してください。

**詳細**:

本アップデートは、Azure Virtual NetworkにおけるEqual-Cost Multi-Path（ECMP）ルーティング機能のパブリックプレビュー提供開始を発表するものです。ECMPルーティングは、同一コストの複数の経路に対してトラフィックを分散させる技術であり、これによりAzure上でユーザー定義ルート（UDR）を用いて、複数のネットワークアプライアンス間で効率的なトラフィック分散が可能となります。

今回のアップデートの目的は、Azure Virtual Networkを利用する顧客が、ネットワークアプライアンスの冗長性やスケーラビリティを向上させるための柔軟なトラフィック分散手法を提供することにあります。従来、UDRでは単一のネクストホップしか指定できず、障害時の冗長化や負荷分散には限界がありました。ECMPルーティングの導入により、2から16個までのネクストホップを単一のUDRで指定できるようになり、トラフィックがこれらのネクストホップ間で均等に分散されます。

技術的には、ユーザーはAzureポータルやAzure CLI、ARMテンプレートなどを用いて、UDRのネクストホップとして複数のIPアドレスを設定します。これにより、仮想ネットワーク内のトラフィックは、指定された複数のネットワーク仮想アプライアンス（NVA）やファイアウォールなどに自動的に分散されます。ECMPアルゴリズムは、パケットのフローごとにハッシュ値を計算し、各ネクストホップへ均等にトラフィックを割り当てる仕組みとなっています。

この機能は、例えば複数台のNVAを用いたインライン型のファイアウォール構成や、ロードバランシングを必要とするネットワークゲートウェイの冗長化構成などに有効です。これにより、障害発生時の可用性向上や、トラフィックのボトルネック解消、ネットワークアプライアンスのスケールアウトが容易になります。

注意点としては、現在パブリックプレビュー段階であるため、本番環境での利用は推奨されません。また、サポートされるネクストホップの数は2から16に限定されており、これ以外の数は設定できません。さらに、既存のUDRやネットワークセキュリティグループ（NSG）との連携においては、従来通りの制約が適用されるため、設計時には十分な検証が必要です。

本機能は、Azure Virtual Networkおよび関連するネットワークアプライアンスサービスと連携して利用できます。これにより、Azure上での高度なネットワークトポロジ設計や、ハイブリッドネットワーク構成の最適化が可能となります。詳細については公式ドキュメントやアップデート情報を参照してください。
