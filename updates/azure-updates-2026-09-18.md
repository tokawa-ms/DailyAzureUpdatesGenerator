### 2. Generally Available: High-scale mesh in Azure Virtual Network Manager

**公開日時**: 2026年09月17日 17:40:33 UTC

**情報源**: Azure Updates API

**カテゴリ**: Launched, Networking, Azure Virtual Network Manager, Features, Management, Services

**要約**:

- 何が更新されたか  
Azure Virtual Network Managerにおいて、「High-scale mesh」機能が一般提供（GA）されました。

- 主な変更点や新機能  
「Connected group」機能を利用することで、1つのメッシュ接続構成内で最大3,000個の仮想ネットワーク（VNet）をデフォルトで相互接続できるようになりました。これにより、大規模なネットワーク環境でも効率的にメッシュ型の接続管理が可能です。

- 影響を受ける対象  
Azure Virtual Network Managerを利用している組織や、複数のVNetをメッシュ接続で管理したいエンタープライズ環境のネットワーク管理者が対象です。

- 注意点があれば記載  
本機能は対応リージョンでのみ利用可能です。また、3,000 VNetを超える場合や、より高いスケールのIP接続が必要な場合は、追加の設定やサポートが必要となる可能性があります。利用前に対象リージョンや制限事項を確認してください。

**詳細**:

Azure Virtual Network Managerにおいて、High-scale mesh using connected groupが一般提供（GA）となりました。このアップデートの背景には、企業や組織がクラウド上で多数の仮想ネットワーク（VNet）を効率的かつ柔軟に接続・管理したいというニーズがあります。従来、複数のVNet間でメッシュ接続を構成する際には、規模や管理の複雑さが課題となっていましたが、今回のアップデートにより、より大規模なネットワーク構成が可能となります。

具体的な機能として、Azure Virtual Network ManagerのHigh-scale meshでは、connected group機能を利用することで、1つのメッシュ接続構成内に最大3,000個のVNetをデフォルトで接続できるようになりました。これにより、複数のVNet間でフルメッシュ型の接続を簡単に構築でき、ネットワークの拡張性と管理効率が大幅に向上します。また、より高いスケールのIP接続もサポートされていることが明記されています。

技術的な仕組みとしては、Azure Virtual Network Managerが提供するconnected groupを用いて、指定したVNet同士を自動的にメッシュ接続します。これにより、各VNet間のルーティング設定や接続管理が一元化され、手動で複雑なピアリング設定を行う必要がなくなります。管理者はAzure PortalやAPIを通じて、メッシュ構成の作成・管理を行うことができます。

活用シナリオとしては、複数の部署やシステムが独立したVNetを持つ大規模な企業環境や、マルチリージョンにまたがるクラウドインフラのネットワーク一元管理が挙げられます。例えば、開発・テスト・本番環境のVNetを一括でメッシュ接続し、セキュアかつ効率的な通信を実現することが可能です。

注意点としては、利用可能なリージョンが限定されているため、導入前に対応リージョンを確認する必要があります。また、デフォルトで3,000VNetまで接続可能ですが、さらに大規模な構成を希望する場合は、追加のスケール設定や制約事項を事前に確認することが重要です。

関連するAzureサービスとの連携としては、Azure Virtual Network Managerは、Azure Virtual Network、Azure Firewall、Network Security Groups（NSG）、およびAzure Monitorなどのネットワーク管理・セキュリティサービスと組み合わせて利用することで、統合的なネットワーク運用と監視が可能です。今回のHigh-scale mesh機能により、これらのサービスとの連携もより大規模かつ効率的に実現できるようになりました。
