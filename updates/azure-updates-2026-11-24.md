**要約**:

- 何が更新されたか

本アップデートは、Foundry IQにおいてEnterprise Knowledge Graphを新たな知識ソースとして追加することを目的としています。これにより、ユーザーは自身のコンテンツ内に存在するエンティティやその関係性に基づいた質問への回答が可能となります。アップデートの背景には、企業が保有する膨大かつ非構造化なデータから、より高度な知識抽出と活用を求めるニーズがあり、従来の単純な情報検索を超えて、コンテンツ間の複雑な関係性を理解し、知識として体系化することが求められています。

具体的な機能としては、Foundry IQがインデックス処理時に、ユーザーが提供するオントロジーをガイドとして用い、非構造化コンテンツからエンティティとその関係性を抽出します。これにより、Knowledge Graphが生成され、エージェントはこのグラフを参照しながら、コンテンツ間の関係性に依存する質問に対して精度の高い回答を提供できるようになります。オントロジーは、企業独自の業務やドメイン知識を反映した構造を定義するものであり、抽出されるエンティティや関係性の精度向上に寄与します。

技術的な仕組みとしては、インデックス時に自然言語処理（NLP）技術を用いて非構造化データからエンティティ抽出と関係性認識を行い、オントロジーによるガイドを受けてKnowledge Graphを構築します。これにより、従来のキーワードベースの検索では困難だった複雑な質問や推論が可能となります。エージェントはこのKnowledge Graphを活用し、質問応答や情報探索の精度を向上させることができます。

活用シナリオとしては、企業内のドキュメントやレポート、メールなどの非構造化データから、業務プロセスや製品情報、人物・組織間の関係性を抽出し、業務知識の体系化やナレッジマネジメントの強化に役立てることが想定されます。また、複雑な問い合わせや意思決定支援、コンプライアンスチェックなどにも応用可能です。

注意点としては、オントロジーの設計や提供が必要であり、抽出精度はオントロジーの質や非構造化データの内容に依存します。また、現時点ではPublic Previewであるため、機能や安定性に制限がある場合があります。

関連するAzureサービスとしては、Foundry IQ自体がAzure上で提供されており、他のデータ分析やAIサービス、ストレージサービスと連携することで、より高度なデータ活用が可能となります。Knowledge Graphの構築や活用は、Azure Cognitive ServicesやAzure Machine Learningとの組み合わせによって、さらに拡張が期待されます。

**カテゴリ**: In preview, AI + machine learning, Microsoft Foundry, Features, Microsoft Ignite

**要約**:

【何が更新されたか】  
Microsoft Foundryにおいて、Guardrailsの体験がアップデートされ、パブリックプレビューとして提供開始されました。

【主な変更点や新機能】  
Guardrailsは、エージェントの実行時安全制御を設定する機能で、分類器、決定論的ルール、LLMベースの判定機能を含みます。今回のアップデートでは、管理者ポリシーでプロジェクトに必要な制御が求められた際、Guardrailsがその要件を明示的に表示するようになりました。これにより、開発者は必要な安全制御を容易に把握し、適切に設定できるようになります。

【影響を受ける対象】  
Microsoft Foundry上でエージェントを開発・運用する開発者や管理者が主な対象です。特に、プロジェクトに安全制御の導入が求められる場合に影響があります。

【注意点】  
本機能はパブリックプレビュー段階のため、正式リリース前の仕様変更や制限がある可能性があります。運用環境での利用時は、最新のドキュメントやサポート情報を確認してください。

**詳細**:

Microsoft FoundryにおけるGuardrailsのアップデートは、開発者がエージェントの実行時安全性を確保するための制御を構成する機能の強化を目的としています。Guardrailsは、エージェントの動作に対して分類器（classifiers）、決定論的ルール（deterministic rules）、および大規模言語モデル（LLM）を活用した判定機能（LLM-based judges）を提供し、プロジェクトの安全性要件を満たすための仕組みを実装しています。管理者がプロジェクトに対して特定のポリシーを要求した場合、Guardrailsはその要求を開発者に提示し、必要な制御の導入を支援します。

今回のアップデートでは、Guardrailsの体験が刷新され、管理者によるポリシー要求がプロジェクト内でより明確に可視化されるようになりました。これにより、開発者はプロジェクトごとに求められる安全性制御を迅速かつ正確に構成できるようになります。具体的には、分類器による入力や出力の検査、決定論的ルールによる条件分岐、LLMを用いた動的な判定など、複数の安全性制御を組み合わせてエージェントの挙動を管理することが可能です。

技術的な仕組みとしては、GuardrailsはFoundry内でエージェントの実行環境に組み込まれ、管理者が設定したポリシーに基づいて各種制御を適用します。分類器は機械学習モデルやルールベースの判定ロジックを用いて入力データや出力データを評価し、決定論的ルールは事前に定義された条件に従ってエージェントの動作を制御します。また、LLM-based judgesは大規模言語モデルの自然言語理解能力を活用し、より柔軟な判定を行うことができます。

このアップデートは、特に複雑な業務プロセスや高い安全性が求められるシナリオで有効です。例えば、金融や医療分野でのエージェント開発において、入力データの検査や出力内容の監査、規制遵守のための条件分岐など、Guardrailsの各機能を活用することで、プロジェクトごとに求められる安全性要件を確実に満たすことができます。

注意点としては、管理者が設定するポリシーに従う必要があり、開発者はGuardrailsが提示する制御要件を正確に実装する必要があります。また、Guardrailsの機能はFoundry内でのエージェント構成に限定されており、他のAzureサービスとの直接的な連携については明記されていませんが、Foundryを利用したプロジェクト全体の安全性向上に寄与するものです。

以上が、Microsoft FoundryにおけるGuardrails体験のアップデートに関する技術者向けの詳細な説明です。

Azure Update「Public Preview: IQ Retriever Zero in Foundry IQ」について詳細に説明します。

技術的な仕組みとしては、イテレーティブリトリーバルモデルが検索プロセスを複数回に分けて実行し、各回で得られた情報を評価しながら次の検索を最適化します。これにより、単一の検索では得られない深い情報や関連性の高い証拠を効率的に収集することが可能です。検索の繰り返しは、設定された予算（例えば、APIコール数や処理時間など）に基づいて管理されます。

注意点としては、検索プロセスが設定された予算内でのみ実行されるため、予算を超える検索は行われません。また、パブリックプレビュー段階であるため、機能やパフォーマンスに関して正式リリース版と異なる可能性があります。運用環境での利用時には、安定性やサポート範囲について事前に確認することが推奨されます。

関連するAzureサービスとの連携については、Foundry IQがAzure上で提供されるサービスであるため、Azureの認証基盤やストレージサービス、データベースサービスとシームレスに統合可能です。これにより、既存のAzure環境内でのデータ活用やセキュリティ管理を維持しつつ、IQ Retriever Zeroの高度な検索機能を利用することができます。
