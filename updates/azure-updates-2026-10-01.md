### 1. Public Preview: SQL performance monitoring for SQL Server on Azure Virtual Machines 

**公開日時**: 2026年09月30日 21:13:13 UTC
**リンク**: [Public Preview: SQL performance monitoring for SQL Server on Azure Virtual Machines ](https://azure.microsoft.com/updates?id=571894)

**アップデートID**: 571894
**情報源**: Azure Updates API

**カテゴリ**: In preview, Compute, Databases, SQL Server on Azure Virtual Machines, Feature

**要約**:

- 何が更新されたか  
SQL Serverが稼働するAzure Virtual Machines向けに、Microsoftが管理するパフォーマンス監視機能のパブリックプレビューが開始されました。

- 主な変更点や新機能  
これまで必要だったカスタムスクリプト作成や複数のテレメトリデータの手動での相関付けが不要となり、AzureポータルからSQL Serverのパフォーマンスを簡単に監視できるようになりました。これにより、CPU使用率やメモリ消費量、I/Oパフォーマンスなどの主要な指標を一元的に把握できます。

- 影響を受ける対象  
Azure Virtual Machines上でSQL Serverを運用している技術者や管理者が主な対象です。特に、運用監視やパフォーマンスチューニングを行う方にとって利便性が向上します。

- 注意点があれば記載  
本機能はパブリックプレビュー段階のため、正式リリース前の機能制限やサポート範囲に注意が必要です。運用環境で利用する際は、プレビューの特性を理解した上でご利用ください。

**詳細**:

Microsoftは、SQL Server on Azure Virtual Machines向けのパフォーマンス監視機能のパブリックプレビューを開始しました。このアップデートの背景には、従来SQL ServerをAzure仮想マシン上で運用する際、パフォーマンス監視のために独自のスクリプト作成や複数のテレメトリ情報の相関付けが必要だったという課題があります。今回のアップデートの目的は、これらの手間を省き、Microsoftが管理する標準化された監視機能を提供することで、運用効率の向上と監視精度の改善を図ることにあります。

具体的な機能としては、SQL Server on Azure Virtual Machinesのパフォーマンスを、カスタムスクリプトや複雑なテレメトリの相関作業なしに監視できる点が挙げられます。これにより、CPU使用率、メモリ消費量、ディスクI/O、クエリ応答時間など、SQL Serverの主要なパフォーマンス指標を一元的に把握することが可能となります。監視データはMicrosoftが管理する仕組みで収集され、ユーザーはAzureポータル上で直感的に状況を確認できます。

技術的な仕組みとしては、Microsoftが提供する監視エージェントやサービスがAzure Virtual Machines上のSQL Serverに対して必要なテレメトリ情報を自動的に収集し、Azureの監視基盤に統合されます。これにより、ユーザーは監視のための追加構成やスクリプト開発を行う必要がなくなります。実装方法としては、Azureポータルから該当機能を有効化することで、監視が開始される仕組みです。

活用シナリオとしては、SQL Server on Azure Virtual Machinesの運用管理者が、パフォーマンス問題の早期発見や障害対応、リソース最適化のために本機能を利用するケースが想定されます。例えば、ピーク時の負荷状況やクエリ遅延の原因分析、リソース不足の兆候把握など、日常的な運用監視やトラブルシューティングに役立ちます。

注意点や制限事項としては、パブリックプレビュー段階であるため、機能やサポート範囲が限定されている可能性があります。また、正式リリース前のため、商用環境での利用には慎重な検証が必要です。

関連するAzureサービスとの連携については、Azure MonitorやLog Analyticsなどの既存の監視・分析サービスと統合されることで、より高度なアラート設定やダッシュボード作成、履歴分析が可能となります。これにより、SQL Serverのパフォーマンス監視をAzure全体の運用管理基盤に組み込むことができます。

詳細は公式アップデートページ（https://azure.microsoft.com/updates?id=571894）をご参照ください。

### 2. Retirement: NVv3-series Azure Virtual Machines

**公開日時**: 2026年09月30日 18:26:47 UTC
**リンク**: [Retirement: NVv3-series Azure Virtual Machines](https://azure.microsoft.com/updates?id=573414)

**アップデートID**: 573414
**情報源**: Azure Updates API

**カテゴリ**: Compute, Virtual Machines, Retirements

**要約**:

- 何が更新されたか  
Microsoft Azureは、NVv3シリーズの仮想マシン（VM）のリタイアを発表しました。対象となるVMは、Standard_NV12s_v3、Standard_NV12hs_v3、Standard_NV24s_v3、Standard_NV24ms_v3、Standard_NV32ms_v3、Standard_NV48s_v3です。

- 主な変更点や新機能  
2026年9月30日をもって、上記NVv3シリーズVMが廃止されます。新機能の追加はなく、既存VMのリタイアが主な変更点です。

- 影響を受ける対象  
NVv3シリーズVMを利用しているユーザーやシステムが影響を受けます。GPUを活用した仮想デスクトップやグラフィックス処理、AI/MLワークロードなどでNVv3シリーズを利用している場合、今後の移行計画が必要です。

- 注意点があれば記載  
リタイア後はNVv3シリーズVMの新規作成や既存VMの利用ができなくなります。該当VMを利用している場合は、2026年9月30日までに他のVMシリーズ（例：NVv4やNCシリーズなど）への移行を検討してください。移行時には性能や互換性、コストなどを十分に確認する必要があります。

**詳細**:

2026年9月30日をもって、Microsoft AzureはNVv3シリーズの仮想マシン（VM）であるStandard_NV12s_v3、Standard_NV12hs_v3、Standard_NV24s_v3、Standard_NV24ms_v3、Standard_NV32ms_v3、Standard_NV48s_v3の提供を終了しました。このリタイアメントは、Azureプラットフォームにおけるハードウェアおよびサービスの最新化、ならびにリソースの最適化を目的としています。NVv3シリーズは、主にGPU（Graphics Processing Unit）を搭載した仮想マシンであり、グラフィックス処理やGPUアクセラレーションを必要とするアプリケーション、たとえば高解像度のリモートデスクトップ、CAD、3Dレンダリング、機械学習の一部ワークロードなどに活用されてきました。

今回の変更内容としては、上記に挙げたNVv3シリーズの各SKUがAzureプラットフォーム上で新規作成・利用できなくなる点が挙げられます。既存のNVv3シリーズVMについても、リタイアメント日以降は稼働を継続できなくなります。これにより、これらのVMを利用しているユーザーは、他のサポートされているGPU搭載VMシリーズ（たとえばNVv4シリーズやNC、NDシリーズなど）への移行を検討する必要があります。

技術的な仕組みとして、NVv3シリーズはNVIDIA Tesla M60 GPUを搭載し、仮想化環境でGPUリソースを分割・割り当てることができる設計となっていました。これにより、複数のユーザーが同一物理GPUを共有しつつ、高いグラフィックス性能を享受できるという特徴がありました。リタイアメントに伴い、これらのハードウェアリソースおよび関連ドライバーのサポートも終了することになります。

活用シナリオとしては、エンタープライズ向けの仮想デスクトップインフラストラクチャ（VDI）、3Dグラフィックスを必要とする設計・開発環境、GPUアクセラレーションを活用したデータ処理や機械学習の前処理などが代表的です。これらのワークロードを引き続きAzure上で運用する場合は、後継となるGPU VMシリーズへの移行計画を早急に立てる必要があります。

注意点として、リタイアメント後はNVv3シリーズVMの新規作成や再起動、スケールアウトなどができなくなります。また、既存のVMも停止・削除されるため、事前にデータのバックアップや移行作業を完了させておくことが重要です。さらに、GPUドライバーやアプリケーションの互換性についても、移行先VMシリーズでの動作検証が必要となります。

関連するAzureサービスとの連携については、NVv3シリーズVMはAzure Virtual DesktopやAzure Batch、AI/MLワークロードなどと組み合わせて利用されてきました。今後は、これらのサービスを利用する際にも、サポートされているGPU VMシリーズを選択する必要があります。詳細については、公式ドキュメントやサポート情報を参照し、適切な移行計画を策定してください。

**リンク**: [Retirement: NVv4-series Azure Virtual Machines](https://azure.microsoft.com/updates?id=573415)

**情報源**: Azure Updates API

**要約**:

【何が更新されたか】  
Microsoft Azureは、NVv4シリーズの仮想マシン（VM）のリタイアを発表しました。

【主な変更点や新機能】  
2026年9月30日をもって、以下のNVv4シリーズVM（Standard_NV4as_v4、Standard_NV4ahs_v4、Standard_NV8as_v4、Standard_NV8ahs_v4、Standard_NV16as_v4、Standard_NV16ahs_v4、Standard_NV32as_v4、Standard_NV32ahs_v4）が利用できなくなります。新機能の追加はありません。

【影響を受ける対象】  
NVv4シリーズVMを利用しているユーザーおよびシステムが影響を受けます。これらはAMD GPUを搭載した仮想マシンで、主にグラフィックス処理やGPUアクセラレーションを必要とするワークロードで利用されています。

【注意点】  
リタイア後は該当VMの新規作成や既存VMの運用ができなくなります。現在NVv4シリーズを利用している場合は、2026年9月30日までに他のVMシリーズ（例：NVv3、NC、NDなど）への移行計画を立てる必要があります。移行時には性能要件や互換性を十分に確認してください。

**詳細**:

2026年9月30日をもって、Microsoft AzureはNVv4シリーズの仮想マシン（VM）であるStandard_NV4as_v4、Standard_NV4ahs_v4、Standard_NV8as_v4、Standard_NV8ahs_v4、Standard_NV16as_v4、Standard_NV16ahs_v4、Standard_NV32as_v4、およびStandard_NV32ahs_v4の提供を終了しました。NVv4シリーズは、AMD Radeon Instinct GPUを搭載した仮想マシンであり、主にグラフィックスアクセラレーションやGPUを必要とするアプリケーションの実行に利用されていました。これらのVMは、リモートデスクトップ、仮想化されたグラフィックスワークロード、CADや3Dモデリングなどのグラフィックス集約型アプリケーションの実行に適していました。

今回のリタイアメントは、Azureプラットフォームのサービス提供の最適化や、より新しいGPU VMシリーズへの移行促進を目的としています。NVv4シリーズのVMは、AMD GPUを搭載し、仮想化技術を用いて複数のユーザーがGPUリソースを分割して利用できる仕組みを持っていました。これにより、コスト効率の高いGPU利用が可能となり、特定のワークロードに対して柔軟なリソース割り当てが実現されていました。

技術的には、NVv4シリーズはGPUパーティショニングをサポートしており、1台の物理GPUを複数の仮想マシンに割り当てることができました。これにより、ユーザーは必要なGPUリソースのみを消費し、無駄なコストを抑えることができました。主な活用シナリオとしては、リモートワーク環境での高性能グラフィックス処理や、開発・テスト用途でのGPUアクセラレーションが挙げられます。また、Azure Virtual DesktopやCitrix、VMware Horizonなどの仮想デスクトップソリューションと連携して利用されるケースも多くありました。

今回のリタイアメントにより、NVv4シリーズのVMは新規作成やスケールアウトができなくなり、既存のVMも利用できなくなります。ユーザーは、今後のワークロードに対して、Azureが提供する他のGPU VMシリーズ（例：NC、ND、NVv3など）への移行を検討する必要があります。移行時には、GPUアーキテクチャやパフォーマンス特性の違い、ドライバーやソフトウェアの互換性などに注意が必要です。

関連するAzureサービスとしては、Azure Virtual DesktopやAzure Batch、AIや機械学習向けのAzure Machine Learningなど、GPUリソースを必要とするサービスとの連携が挙げられます。NVv4シリーズのリタイアメントに伴い、これらのサービスを利用する際には、対応するGPU VMシリーズへの切り替えが必要となります。今後は、より新しいVMシリーズを活用し、最新のGPU技術やパフォーマンスを享受することが推奨されます。

### 4. Public Preview: Ubuntu 26.04 support in AKS

**公開日時**: 2026年09月30日 17:11:11 UTC
**リンク**: [Public Preview: Ubuntu 26.04 support in AKS](https://azure.microsoft.com/updates?id=573214)

**アップデートID**: 573214
**情報源**: Azure Updates API

**カテゴリ**: In preview, Compute, Containers, Azure Kubernetes Service (AKS), Feature

**要約**:

【何が更新されたか】  
Azure Kubernetes Service（AKS）でUbuntu 26.04のサポートがパブリックプレビューとして提供開始されました。

【主な変更点や新機能】  
Ubuntu 26.04をベースとした「Ubuntu2604 OS SKU」が導入され、Ubuntu Minimalイメージを利用したノードプールの構築が可能になりました。これにより、最新のUbuntu LTSリリースに対応した環境をAKS上で利用できます。

【影響を受ける対象】  
Ubuntuノードプールを使用しているAKSユーザーや、OSのバージョン管理・セキュリティ対応が必要な技術者が対象となります。特に、長期サポート（LTS）バージョンへの移行を検討しているチームに影響があります。

【注意点】  
OSのアップグレード時には、パッケージ構成やセキュリティ、互換性に関する懸念が生じる可能性があります。Ubuntu 26.04への移行を検討する際は、既存アプリケーションやワークロードの動作確認を十分に行う必要があります。パブリックプレビューのため、本番環境での利用には慎重な検証が求められます。

**詳細**:

Azure Kubernetes Service（AKS）におけるUbuntu 26.04のサポートがパブリックプレビューとして提供開始されました。本アップデートの背景には、AKS上でUbuntuノードプールを運用しているチームが、UbuntuのLTS（Long Term Support）リリースに合わせてOSを最新化し続ける必要があるという要件があります。OSのバージョン移行時には、パッケージ構成やセキュリティ、互換性に関する懸念が生じることが多く、これらの課題に対応するために新しいUbuntu 26.04のサポートが導入されました。

今回のアップデートでは、Ubuntu 26.04をベースとした新しいOS SKU「Ubuntu2604」がAKSのノードプールで利用可能となります。Ubuntu2604は「Ubuntu Minimal」を採用しており、必要最小限のパッケージ構成で提供されるため、不要なソフトウェアが排除され、セキュリティリスクの低減や起動時間の短縮、リソース消費の最適化が期待できます。AKSのノードプール作成時や既存ノードプールのアップグレード時に、この新しいOS SKUを選択することで、Ubuntu 26.04環境を迅速に構築することが可能です。

技術的な仕組みとしては、AKSのノードプール設定時にOS SKUとして「Ubuntu2604」を指定することで、Azureが提供する公式イメージを用いてノードがプロビジョニングされます。これにより、クラウドネイティブな運用やCI/CDパイプラインの自動化、セキュアなコンテナ実行環境の構築が容易になります。Ubuntu Minimalの採用により、ベースイメージの軽量化とセキュリティパッチの適用効率が向上しています。

活用シナリオとしては、最新のUbuntu LTS環境でアプリケーションを実行したい場合や、セキュリティ要件の高いシステム、リソース効率を重視したマイクロサービスアーキテクチャの構築などが挙げられます。特に、長期的なサポートと安定性を求める企業や、OSバージョンごとの機能差異に対応したい開発チームにとって有用です。

注意点としては、パブリックプレビュー段階であるため、本番環境での利用には慎重な検証が必要です。また、Ubuntu Minimalの特性上、従来のUbuntuイメージに含まれていた一部パッケージが省略されている場合があり、アプリケーションや運用ツールの依存関係に応じて追加インストールが必要となるケースがあります。

関連するAzureサービスとの連携については、AKSの標準機能として提供されるため、Azure MonitorやAzure Policy、Azure Security Centerなどのサービスと組み合わせて、運用監視やセキュリティ管理を一貫して実施することが可能です。Ubuntu 26.04サポートの導入により、AKS環境におけるOS選択肢が拡充され、より柔軟なクラウドネイティブ運用が実現します。
