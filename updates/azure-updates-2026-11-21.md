**要約**:

【何が更新されたか】

【主な変更点や新機能】  
開発者がエージェントを構築する際、エージェントタイプ、モデル、ツールボックス、ガードレールに関する関連ポリシーが両環境で表示されるようになりました。これにより、ポリシー違反時には警告が発生し、ガバナンス遵守を支援します。

**詳細**:

具体的な機能としては、Foundry CanvasおよびVS CodeのFoundry Toolkit上で、エージェントの構成要素ごとに関連するガバナンスポリシーが自動的に提示される仕組みが導入されています。これにより、開発者はエージェントの種類や選択したモデル、組み込むツールボックス、設定したガードレールに対して、リアルタイムでポリシーの警告やガイダンスを受け取ることができます。警告やガイダンスは、エージェントの設計段階でのリスクや非推奨事項を事前に把握し、Azure上での運用時に問題が発生しないようにするためのものです。

技術的な仕組みとしては、Foundry CanvasとVS CodeのFoundry Toolkitが、Microsoft Foundryが定義するガバナンスポリシーを内部的に参照し、エージェント構築時の各ステップで適切なポリシー情報を表示するよう設計されています。これにより、開発者はポリシー違反の可能性がある構成や設定を即座に認識し、修正や調整を行うことが可能です。

活用シナリオとしては、エージェント開発時にガバナンスを重視するプロジェクトや、複数の開発者が共同でエージェントを設計・実装する場合に、統一されたポリシー遵守を促進する用途が考えられます。また、Azure上でエージェントを運用する際のセキュリティやコンプライアンス要件を満たすため、事前にポリシー違反を防ぐ仕組みとして有効です。

注意点としては、提示されるポリシーや警告がMicrosoft Foundryの定義に基づくものであるため、独自要件や組織固有のガバナンスルールが必要な場合は、追加の対応や設定が必要となる場合があります。また、Foundry CanvasとVS CodeのFoundry Toolkitを利用することが前提となるため、これらのツールが導入されていない環境では本機能を活用できません。

関連するAzureサービスとしては、Foundryを中心としたエージェント開発環境がAzure上で提供されているため、Azure Machine LearningやAzure AIサービスと連携し、エージェントの構築・運用におけるガバナンス強化が期待できます。今回のアップデートは、Azure上でのエージェント開発におけるガバナンスの実践を支援する重要な機能追加となっています。

**カテゴリ**: Compute, Containers, Internet of Things, Azure Functions, Retirements, Microsoft Ignite

**要約**:

【何が更新されたか】

【主な変更点や新機能】  
今回のアップデートでは、Azure Functions OpenAI Extensionのサポート終了が明示されており、今後はOpenAI、Microsoft Foundry、またはAzure AI Search SDKなど、用途に応じて直接これらのSDKへの移行が推奨されています。新機能の追加はありません。

【影響を受ける対象】  
Azure Functions OpenAI Extensionを利用している開発者やシステム管理者が対象となります。特に、.NETアプリケーションで同拡張機能を利用している場合、移行対応が必要です。

【注意点】  
2027年4月20日以降はAzure Functions OpenAI Extensionの公式サポートが終了するため、セキュリティや機能面でのサポートが受けられなくなります。該当するシステムは早めにOpenAI、Microsoft Foundry、Azure AI Search SDK等への移行計画を立ててください。サポート終了までに移行を完了することが推奨されます。

**詳細**:

Azure Functions OpenAI Extensionのサポートは2027年4月20日をもって終了します。このアップデートの背景には、Azureがより直接的かつ最新のSDKへの移行を促進し、今後の機能拡張やセキュリティ対応を効率化する目的があります。これにより、従来Azure Functions OpenAI Extensionを利用していた開発者は、該当するシナリオに応じてOpenAI SDK、Microsoft Foundry SDK、またはAzure AI Search SDKへ移行する必要があります。

具体的な変更内容としては、Azure Functions OpenAI Extensionの公式サポートが終了するため、今後はバグ修正やセキュリティアップデートが提供されなくなります。これにより、既存の.NETアプリケーションやAzure FunctionsでOpenAI Extensionを利用している場合、サポート終了日までに移行を完了することが求められます。移行先のSDKは、それぞれの用途やシナリオに応じて選択する必要があります。たとえば、自然言語処理や生成AIを利用する場合はOpenAI SDK、検索機能を強化したい場合はAzure AI Search SDKが推奨されます。

技術的な仕組みとして、Azure Functions OpenAI ExtensionはAzure Functionsのトリガーやバインディングを通じてOpenAIのAPIを簡易に呼び出すことが可能でした。今後は、各SDKを直接.NETアプリケーションやAzure Functionsから利用する形となり、API呼び出しや認証、レスポンス処理などをSDKの標準機能に従って実装する必要があります。これにより、より細かい制御や拡張性が得られる一方、移行作業やコードの修正が必要となります。

活用シナリオとしては、チャットボットや自動応答システム、テキスト生成、検索機能の強化などが挙げられます。これらのシステムをAzure Functions上で構築していた場合、今後はOpenAI SDKやAzure AI Search SDKを直接組み込むことで、同様の機能を実現できます。

注意点として、サポート終了後はAzure Functions OpenAI Extensionの利用による障害やセキュリティリスクへの対応ができなくなるため、必ず期限までに移行を完了させる必要があります。また、移行先のSDKはそれぞれ認証方式やAPI仕様が異なるため、事前にドキュメントを確認し、適切な実装を行うことが重要です。

関連するAzureサービスとの連携については、Azure Functionsは引き続き各種SDKと連携可能です。たとえば、Azure Key VaultによるAPIキー管理や、Azure Monitorによるログ管理、Azure Logic Appsとの統合など、従来通りのサービス連携が可能です。今後は、より直接的なSDK利用による拡張性とセキュリティの向上が期待されます。

詳細は公式アップデートページ（https://azure.microsoft.com/updates?id=579952）をご参照ください。

### 5. Public Preview: Multi-turn evaluation in Microsoft Foundry

【何が更新されたか】  
Microsoft Foundryにおいて、マルチターン評価機能がパブリックプレビューとして公開されました。

【主な変更点や新機能】  
これまで個々の応答単位で評価していたエージェントの会話品質を、会話全体（複数ターン）で評価できるようになりました。これにより、単一の応答が正しく見えても、会話全体の流れや文脈に沿った品質評価が可能となります。

【影響を受ける対象】  
Microsoft Foundryを利用している開発者や技術者、特に会話型AIエージェントの品質管理や評価を行う方が対象となります。会話の精度やユーザー体験向上を重視するプロジェクトに有用です。

【注意点】  
本機能はパブリックプレビュー段階のため、正式リリース前の仕様変更や制限がある可能性があります。運用環境での利用時は、プレビュー版であることを考慮し、十分な検証を行ってください。

**詳細**:

Microsoft Foundryにおいて、マルチターン評価（Multi-turn evaluation）がパブリックプレビューとして公開されました。本アップデートの背景には、エージェント型AIやチャットボットなどの会話型システムにおいて、単一の応答だけでなく、会話全体の品質を評価する必要性が高まっていることがあります。従来の評価手法では、個々のレスポンスが正しいかどうかのみを判定していましたが、実際の運用では会話の流れや文脈を踏まえた全体的な評価が求められています。

今回のアップデートでは、Microsoft Foundry上でエージェントの会話全体を品質基準に基づいて評価できる機能が追加されました。これにより、単一の応答が正しく見えても、会話全体の文脈や流れに沿っていない場合には、より適切な評価が可能となります。技術的には、会話履歴全体を対象とした評価プロセスが導入されており、エージェントの応答が連続する複数ターンのやり取りを一括して分析することができます。

実装方法としては、Microsoft Foundryの評価機能を利用して、会話ログをアップロードし、指定した品質基準に従って会話全体を評価することが可能です。評価結果は、エージェントの改善や品質管理に活用できます。例えば、カスタマーサポート用チャットボットの応答品質を、単一の質問・回答だけでなく、顧客との一連のやり取り全体として評価することで、より実用的なフィードバックを得ることができます。

活用シナリオとしては、エージェントのトレーニングや品質保証、運用後のパフォーマンス分析などが挙げられます。特に、複雑な問い合わせや長い会話が発生する業務において、会話全体の流れや一貫性を重視した評価が重要となります。

注意点としては、パブリックプレビュー段階であるため、機能や仕様が今後変更される可能性があること、また評価基準の設定や会話ログの管理において、十分な検証が必要となることが挙げられます。

関連するAzureサービスとしては、Microsoft FoundryがAzure上で提供されているため、Azure AIやAzure Machine Learningなどのサービスと連携して、エージェントの開発・運用・評価を統合的に管理することができます。今回のアップデートは、会話型AIの品質向上や運用効率化に寄与する重要な機能追加となっています。
