**要約**:

【何が更新されたか】  
Azure Cosmos DBにおいて「Safe Key Rotation」機能が一般提供（GA）されました。

【主な変更点や新機能】  
Safe Key Rotationでは、各アカウントキーが最後に使用された日時のメタデータを確認できるようになりました。これにより、キーのローテーションや廃止前に、どのキーが現在アクティブで使用されているかを把握できます。可視性が向上することで、不要なキーの誤ったローテーションによるサービス停止リスクを低減できます。

【影響を受ける対象】  
Azure Cosmos DBを利用しているすべてのユーザーおよび管理者が対象となります。特に、セキュリティポリシーに基づき定期的なキーのローテーションを実施している技術者にとって有用な機能です。

【注意点】  
キーの使用状況を確認した上でローテーションや廃止を行うことで、サービスへの影響を最小限に抑えることができます。運用時には、最新のメタデータを参照し、アクティブなキーの特定を確実に行うよう注意してください。

**詳細**:

Azure Cosmos DB Safe Key Rotationが一般提供となりました。このアップデートの背景には、クラウドサービスにおける認証情報の管理強化と、セキュリティリスクの低減が挙げられます。特に、アカウントキーの定期的なローテーションや廃止は、認証情報漏洩や不正アクセスの防止において重要な対策ですが、従来はどのキーが実際に利用されているかを把握することが困難でした。今回のアップデートにより、Azure Cosmos DBの各アカウントキーについて、最終使用日時のメタデータを確認できるようになりました。

具体的な機能として、管理者はAzure Cosmos DBのポータルやAPIを通じて、各アカウントキーが最後に使用されたタイムスタンプ情報を取得できます。これにより、キーの利用状況を可視化し、アクティブなキーと未使用のキーを区別することが可能です。キーのローテーションや廃止を行う際、実際に利用されているキーを誤って無効化するリスクを低減できます。また、不要なキーの早期廃止や、定期的なローテーション計画の策定にも役立ちます。

技術的な仕組みとしては、Azure Cosmos DBが認証時に各アカウントキーの使用履歴を記録し、その情報をメタデータとして管理者に提供します。これにより、管理者はリアルタイムでキーの使用状況を把握でき、セキュリティポリシーに基づいた運用が可能となります。実装方法としては、Azure PortalやCLI、REST APIを利用してキーの使用履歴を参照できます。

活用シナリオとしては、例えば、運用中のシステムで複数のアプリケーションやサービスがCosmos DBにアクセスしている場合、どのキーがどのタイミングで使われているかを把握し、ローテーション計画を立てる際に活用できます。また、キーの漏洩が疑われる場合や、セキュリティ監査の際にも、使用履歴を確認することで迅速な対応が可能です。

注意点としては、キーの使用履歴が記録されるタイミングや保持期間、または一部のアクセス方法では履歴が取得できない場合がある点に留意する必要があります。詳細な制限事項については公式ドキュメントを参照してください。
